AI Tuning

Customise the system prompt that is sent to the language model before every conversation. Changes take effect immediately for all new messages — no restart required. Use this to adjust the assistant's tone, scope, or behaviour to suit your teaching or research goals.

How It Works

The diagram below shows the full request flow. A user message is combined with the system prompt you define here and sent to the local LLM. Depending on the response, the chatbot either returns a direct text answer or produces a SQL query destined for the student database.

Tips for writing effective system prompts
  • Be specific about the assistant's role and audience (e.g. "You are a tutor for first-year computer science students").
  • List topics the assistant should and should not discuss.
  • Define the response style — length, formality, use of examples.
  • If using the SQL agent format, keep the *** [SQL Query] instruction intact.
